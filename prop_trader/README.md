# Prop Trader 연구 엔진

여러 종목의 거래량 동반 돌파를 탐지하고 거래 근거, 체결, 손익을 기록하는 오프라인 연구용 구현입니다. Python 표준 라이브러리만 필요합니다. 기존 financial_pjt, pyupbit, ta 소스는 변경하지 않습니다.

**현재 우선 작업은 아래 돌파 전략이 아니라 TimesFM 기반 5개 봉 종가 예측입니다.** 돌파/거래량 급증 전략은 실데이터 백테스트에서 성능이 좋지 않아(2024-04~2025-12 홀드아웃 약 -5%, `runs/backtest/REPORT.md`) 지금은 baseline으로만 유지합니다. 예측 시스템 설명과 실행 방법은 [FORECASTING.md](FORECASTING.md)를 보세요.

## 실행

워크스페이스 루트에서:

```sh
python3 -m prop_trader --demo --out runs/demo
python3 -m prop_trader --csv candles.csv --out runs/research
python3 -m unittest discover -s prop_trader/tests -v
```

`--allow-short`는 숏 매매를 시뮬레이션하는 연구 옵션입니다. 실거래 주문은 없습니다. 펀딩비, 차입 가능 여부, 증거금 및 강제청산은 아직 모델링하지 않습니다.

CSV 컬럼은 `timestamp,symbol,open,high,low,close,volume`이며 timestamp에는 시간대가 필요합니다. UTC로 정규화하고 시간순 정렬합니다. 모든 종목은 같은 봉 주기와 동일한 호가 통화를 사용해야 합니다. 열린 포지션의 봉이 누락되면 중단합니다. 예:

```csv
timestamp,symbol,open,high,low,close,volume
2025-01-01T00:00:00Z,AAA,100,101,99,100,1200
2025-01-01T00:01:00Z,AAA,100,102,99,101,1600
```

## 판단 및 실행 규칙

- 직전 20개 봉의 고가 돌파와 평균 거래량의 2배 이상을 매수 후보로 선정합니다. 숏 옵션은 직전 저가 이탈에 대칭 적용합니다.
- 현재 봉 종가에서 판단하고 다음 봉 시가에서 실행합니다. 후보가 많으면 거래량 배수 순으로 처리합니다.
- 초기 자금 10,000, 거래당 손실 예산 0.5%, 종목당 최대 배분 20%, 동시 3개 포지션입니다. 총 명목 노출은 진입 시 자산 이내로 제한합니다.
- 진입가 대비 2.5% 손절, 5% 익절, 편도 수수료와 슬리피지 각각 0.1%를 적용합니다. 손실 예산에는 예상 왕복 비용을 포함하나 갭 손실은 이를 초과할 수 있습니다.
- 같은 봉에서 손절과 익절이 모두 닿으면 손절을 우선합니다. 손절가를 건너뛴 갭은 시가 기준으로 체결합니다.
- UTC 일 시작 전 평가자산 대비 3% 하락을 봉 시가·종가에서 감지하면 전량 청산하고 당일 진입을 중단합니다. 틱 단위 손실 제한을 보장하지 않습니다.
- 반대 신호는 기존 포지션을 닫은 뒤 새 방향으로 진입합니다. 종료 시 열린 포지션을 비용 포함 청산합니다.

## 결과

- `summary.json`: 설정, 데이터 출처, 최종 자산, 수익률, 최대 낙폭, 거래 수
- `events.jsonl`: 신호, 진입, 청산, 일일 중단과 근거
- `equity.csv`: 시점별 평가자산

데모는 고정 난수로 만든 합성 데이터이며 실전 성과의 증거가 아닙니다. 반복 실행 시 지정 출력 폴더의 결과 파일을 덮어씁니다.

## 다음 구현 범위

실제 데이터 반복 검증 도구가 추가되었습니다:

```sh
python3 -m prop_trader.download
python3 -m prop_trader.research
python3 -m prop_trader.plot_results
```

다운로더는 Binance 공개 시간봉과 체크섬을 저장합니다. 연구 도구는 18개 설정의 학습, 상위 3개 검증, 최종 기간 평가, 비용 스트레스, 개별 종목 실험과 매수 보유 비교를 실행합니다. 결과는 `runs/backtest/REPORT.md`에 저장됩니다. 차트 생성만 matplotlib가 필요합니다. 공개 과거 데이터 다운로드에는 네트워크가 필요하며 계정 키는 사용하지 않습니다.

1. 거래소·대상 시장 확정 후 읽기 전용 캔들/체결/호가 수집 및 저장.
2. 시가총액·유통량으로 소형 코인 집합 정의. 호가 깊이, 스프레드, 거래대금으로 거래 가능한 후보 필터링.
3. 시장 국면, 상대 강도, 여러 시간대 추세를 반영한 후보 점수와 진입 규칙 비교.
4. 실제 과거 데이터, 상장폐지 종목, 기간 외 검증, 워크포워드 검증과 비용 민감도 평가.
5. 거래소별 주문 상태·부분 체결·재시작 복구와 실시간 모의매매. 이후 실거래 연결.

현재는 실시간 수집, 시가총액 선별, 호가 유동성 평가, 지표 라이브러리 연결, 체결량 제한이 없습니다. OHLC만으로 봉 내부 가격 경로와 실제 체결 가능성을 알 수 없으며, 고정 비용 모델에는 시장 충격이 반영되지 않습니다. 거래별 손익은 비용 차감 후 값이고 최대 낙폭은 기록된 평가 시점 기준입니다.
