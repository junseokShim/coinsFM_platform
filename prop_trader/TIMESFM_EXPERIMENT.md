# TimesFM 비교 실험 제안

상태: 공식 문서와 로컬 환경 확인 완료. 모델 다운로드·추론·미세조정 미실행.

최근 관측을 context로 제공하는 것은 기본적으로 가중치를 갱신하지 않는 zero-shot 예측이다. 최근 구간의 context/미래 정답 쌍으로 LoRA adapter를 최적화하는 것은 미세조정이다.

실험 후보는 TimesFM 2.5 200M. 공식 저장소는 2.5까지 가중치 Apache-2.0, 3.0 가중치는 비상업·비프로덕션 제한을 명시한다. 실거래 목적의 기본 후보는 2.5로 한다.

1. 입력: 종목별 최근 512개 완료 시간봉의 로그 가격. 예측: 6시간 및 24시간 가격 변화. 전처리 통계는 과거 입력에서만 계산.
2. 비교: 마지막 가격 유지, 기존 돌파 전략, 추세·눌림 전략, TimesFM zero-shot, TimesFM LoRA.
3. LoRA: 각 기준 시점 이전 90일로 학습, 이후 14일로 검증, 그 다음 14일로 평가하는 순차 실험. 모든 학습 정답은 학습 경계 이전에 끝나야 한다. 기간과 설정은 실행 전 동결.
4. 상승 사례만 모으지 않는다. 하락·횡보·급등 실패 구간을 포함한다. 평가 구간의 실제 미래 거래량·가격을 covariate로 넣지 않는다.
5. 모델은 예상 수익률과 예측 구간을 제공하고 별도 주문·위험 관리 엔진이 거래를 결정한다. 모델 분위수를 교정 없이 성공 확률로 간주하지 않는다.
6. 평가: 예측 오차·방향 정확도와 비용 차감 손익·낙폭·거래 수 모두 비교. naive 기준을 이기지 못하면 채택하지 않는다.
7. 체크포인트 출시일과 학습 데이터 범위를 기록한다. 과거 가격이 사전학습에 포함됐을 가능성이 남으면 해당 결과를 완전히 미관측인 평가로 주장하지 않는다. 출시 후 데이터 및 전진 모의매매로 추가 확인한다.

현재 arm64 Python 환경에 torch는 있지만 timesfm, transformers, peft는 없다. 독립 환경에 버전을 고정해 설치하고 소규모 추론 시간을 측정한 뒤 전체 실험의 계산량을 정한다.

공식 출처:
- https://github.com/google-research/timesfm
- https://github.com/google-research/timesfm/tree/master/timesfm-forecasting/examples/finetuning

기존 눌림 전략 개발 비교: runs/pullback/development.csv 및 frozen.json. 4개 후보 모두 2024/2025 양 구간 수익 조건을 통과하지 못했다. 2026 평가 데이터는 아직 다운로드·평가하지 않았다.
